# Donations

Outpage is free to self-host, forever. There is no paid tier, no subscription,
and no feature will ever be gated on money.

If Outpage kills your weekly status chore and you want to fund it, donations
are the only mechanism:

- **Ethereum / USDC (ERC-20):** `0x85ee7E71f762d772599cbF1EC20E651B30657521`
- **Bitcoin:** `bc1qxe2zx5tv3hdreaej6s2x4p7han85uey828rrhg`

Both addresses are printed by `outpage donate` and shown on `/donate` of any
served status page and in the GUI/TUI footers.

## Attribution (optional)

Donations are anonymous by default. If you want attribution, include a memo
(ETH/USDC) or a message-signature note referencing the commit or issue you
funded. There is no ledger of donors inside the product.

## Wallet changes

Changing, adding, or removing an address requires 4/4 maintainer consensus
plus 30-day public notice, per [GOVERNANCE.md](../GOVERNANCE.md).
